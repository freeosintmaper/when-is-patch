Частые вопросы
Когда выйдет следующий патч?

Точной даты нет — Valve не публикует расписание патчей. Сайт сопоставляет паузу после официального патча и активность служебных веток. Эти показатели помогают следить за изменениями, но не позволяют надёжно вычислить дату выхода.

Что такое Staging и Experimental?

Это служебные ветки Valve. Их активность видна по публичным данным о версиях, но сама по себе не доказывает подготовку релиза. Staging и Experimental — косвенные индикаторы, а не расписание обновлений.

Почему я вижу разные номера Public и Staging?

У каждой ветки свой счётчик. Номера Public и Staging — не одно и то же число в разных местах, а разные ветки с независимой нумерацией. Сравнивать имеет смысл только смену версии внутри одной ветки.

Что делает кнопка «Перезагрузить данные»?

Она перечитывает файлы, которые уже опубликованы на GitHub Pages. Кнопка не запускает новый GitHub Actions workflow. Сборщик автоматически проверяет источники примерно каждые 15 минут, но расписание GitHub может задерживаться.

Откуда данные и как часто обновляются?

Версии веток — из открытых данных сообщества, которые агрегируют SteamDB. Список патчей — из официального API Dota 2. Обновление запускается автоматически по расписанию через GitHub Actions. Данные не моментальные: если Valve выложила сборку минуту назад, увидишь её после следующего запуска.
