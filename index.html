Частые вопросы
Когда выйдет следующий патч?

Точной даты нет — Valve объявляет патч в момент выхода. Сайт показывает признаки: пауза после последнего патча, смены Staging и активность Experimental. Чем больше «красных» сигналов — тем ближе обновление, но это не гарантия.

Что такое Staging и Experimental?

Это закрытые служебные ветки Valve. Staging — «окно выдачи»: сюда Valve кладёт сборки незадолго до релиза. Experimental — «мастерская»: меняется почти каждый день. Обе видны только по номеру версии через публичные данные Steam.

Почему я вижу разные номера Public и Staging?

У каждой ветки свой счётчик. Public 6957 и Staging 3332 — это не одно и то же число в разных местах, а разные ветки с независимой нумерацией. Сравнивать имеет смысл только смену версии внутри одной ветки.

Откуда данные и как часто обновляются?

Версии веток — из открытых данных сообщества, которые агрегируют SteamDB. Список патчей — из официального API Dota 2. Обновление запускается автоматически по расписанию через GitHub Actions. Данные не моментальные: если Valve выложила сборку минуту назад, увидишь её после следующего запуска.
